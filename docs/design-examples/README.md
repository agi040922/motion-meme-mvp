# Social Design References

## 목적

이 문서는 Motion Meme의 소셜 화면 방향을 잡기 위한 참고 캡처를 정리한 문서다.

현재 참고 방향은 전체적으로 아래 키워드로 요약된다.

- 미니멀 모노톤 소셜
- Threads 계열의 조용한 UI
- 화면 중앙 대형 카드 컨테이너
- 좌측 고정 아이콘 레일
- 부드러운 라운드와 얇은 라인
- 과한 장식보다 여백과 정보 밀도 중심

## 제안 이름

이 레퍼런스 묶음의 내부 별칭은 아래로 잡는다.

`Quiet Mono Social`

짧게는 아래처럼 불러도 된다.

- Quiet Mono
- Soft Thread UI
- Mono Social Rail

## 파일 정리

### 1. 메인 피드

- 파일: `social-feed-home-reference.png`
- 설명: 기본 소셜 피드 화면. 좌측 레일, 중앙 카드형 피드, 상단 정렬 선택이 핵심.

### 2. 검색 / 팔로우 추천

- 파일: `social-search-follow-reference.png`
- 설명: 검색창 + 추천 계정 리스트 + 강한 팔로우 버튼 구조 참고용.

### 3. 글쓰기 모달

- 파일: `social-compose-modal-reference.png`
- 설명: 어두운 오버레이 위에 둥근 compose modal이 뜨는 방식 참고용.

### 4. 프로필 메인

- 파일: `social-profile-reference.png`
- 설명: 프로필 소개, 태그, 팔로우 수, 탭 구조가 한 카드 안에 정리된 화면.

### 5. 프로필 메뉴 레이어

- 파일: `social-profile-menu-reference.png`
- 설명: 좌측에서 뜨는 설정/저장/좋아요 성격의 라이트 메뉴 레이어 참고용.

## 이 레퍼런스에서 가져갈 것

- 라이트 그레이 기반의 차분한 전체 배경
- 중앙 집중형 카드 레이아웃
- 좌측 사이드 레일 내비게이션
- 큰 라운드와 낮은 대비의 경계선
- 피드/프로필/검색/글쓰기 흐름의 통일감

## 이 레퍼런스에서 그대로 가져오지 않을 것

- 지나치게 평평한 감정선
- 밈/스테이지 서비스 특유의 리액션 연출 부족
- 게임성이나 퍼포먼스성이 약한 상태

즉, 소셜 구조는 이 레퍼런스를 따르되, Motion Meme 쪽에서는 아래를 추가로 섞어야 한다.

- 스테이지 진행감
- 업로드 직전 결과 영상 강조
- 밈 오버레이와 점수 연출
- 로그인 유도형 랜딩과 연결되는 브랜드 톤

## 적용 메모

실제 제품에는 아래 방식으로 녹이는 것이 좋다.

- 소셜 구조: 이 레퍼런스와 유사
- 플레이/결과 화면: 더 강한 무대 연출
- 프로필: 이 레퍼런스를 기본으로 하되 대표 밈, 최고 점수, 최근 영상 강조
- 피드: 기본은 조용하지만 썸네일과 결과 영상 카드만 더 강하게
